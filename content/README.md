# content/ — 格律知识与词牌内容源

本目录是 M4（知识内容）的交付物，供数据构建脚本 (`scripts/build-data.mjs`) 合并进 `data/knowledge.json`
以及用于校正《声律启蒙》韵部例字。**本目录只存放内容源，不直接对外提供接口。**

## 文件

| 文件 | 内容 | 形状 |
|---|---|---|
| `cards.json` | 12 张格律知识卡（四声平仄 → 学习路线，按展示顺序排列） | `[{id,title,summary,paragraphs,examples:[{text,note}]}]`，见 `docs/contract.md` §2.5 |
| `ci-cards.json` | 15 张词牌卡 | `[{id,name,aliases,form,rhyme,note,example}]`，见 §2.5 |
| `yun-overrides.json` | 平声三十韵部各 4–6 个常用韵脚例字，构建期用于校正从《声律启蒙》提取的 `exampleChars` | `{"<韵目>": ["字", ...]}`，键名与 §2.4 的 `name` 一致（如 `"一 东"`） |
| `pingshui-supplement.json` | **QA 辅助文件**（不参与 knowledge.json 合并）：用公版平水韵表校验诗韵脚时的归一化补丁——t2s 归一提示、表内失收字的平声归类、通行邻韵分组、首句借韵建议与已知表问题 | 见文件内 `_note` / `suggestedGateOrder` |
| `anthology-qa.md` | **QA 记录**：仓库自带《唐诗三百首》《宋词三百首》作精选主源的核验结论（剔除/修正清单、宋词缺字与作者截断、词牌合称归一、15 词牌覆盖） | Markdown，≤120 行 |

构建约定（与 data-pipeline 对齐）：

- `cards.json`、`ci-cards.json` 均为**裸数组**，直接对应 `knowledge.json` 的 `cards` / `ciCards`。
- 卡片顺序即客户端展示顺序；`id` 全局唯一、稳定，不随文案修改而变。
- `yun-overrides.json` 的键共 30 个（上卷 15 + 下卷 15），与 `yun.json` 的章节 `name` 逐字一致。
- 文本统一为**简体中文**，客户端不再做繁简转换。

## 来源与许可

- **格律知识**：属于公版常识，按通行格律学体系（王力《诗词格律》一系的教学表述）自行撰写，
  非逐字摘录或改写任何受版权保护的现代著作；规则表述（四声平仄、粘对、对仗、孤平、拗救、
  三平调、词牌基础）均为历代诗话、韵书、词谱中的通行说法。
- **例句**：全部取自公版古典诗词（《全唐诗》《全宋诗》、宋词名篇等，作者逝世均已逾千年，
  属公有领域）。例句文本可随项目 MIT 许可分发。
- **韵部例字**：据《平水韵》及公版蒙学读物《声律启蒙》原文核对。`_ref/poetry-data` 中的
  `chinese-poetry` 数据集以 MIT 许可提供，仅作为校对参照，未复制其整理性注释。
- **词牌信息**：字数、片数、韵脚概括依据公版词谱（《钦定词谱》《词律》）与《词林正韵》的通行常识，
  不逐字抄录词谱。
- **参考书目**：正文提到的《平水韵》《声律启蒙》《词林正韵》《词律》《钦定词谱》及王力《诗词格律》
  仅作书名指引，未引用其正文。

## 繁简处理

《声律启蒙》原书、唐宋诗原文多为繁体。本目录内文字一律转写为简体，转写只改字形、不改字句；
词汇与标点以通行简体整理本为准。词牌名、韵目名（如「一 东」）保留通行写法。

## 校对说明

- 每张卡 `summary` ≤40 字，`paragraphs` 2–4 段且每段 ≤160 字，`examples` 1–3 条。
- 格律表述尽量采用无争议的通行说法；对可能存在异说的细节（如个别词的平仄两读、词牌别名的取舍）
  宁缺毋滥，已在交付说明中标注供 Lead 复核。
- 若需修改本目录内容，请同时检查 `data/knowledge.json` 的构建结果与 `docs/contract.md` §2.5 的一致性。
