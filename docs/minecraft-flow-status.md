## Wiki 读取量（2026-11-24 调整后）

## 解析容错（2026-11-25）

近 3 小时 312 次决策里有 17 次（5.4%）落在「模型没有给出合法工具」。

原因：原来只取回复里**第一个 `{` 到最后一个 `}`** 做 JSON.parse，
模型一旦把解释文字、代码块或多个对象混在一起，整段就解析失败。

现在改成括号配平扫描（`minecraft-parse.mjs`）：

- 跳过字符串内的括号与转义；
- 逐个尝试候选对象，取第一个 tool 合法的；
- 前面有坏 JSON 也能解析后面的合法命令。

示例：`我先想想 {不是json} 然后 {"tool":"mc_wait",...}` → 仍能正确得到 mc_wait。
