## 配方查询

新增 `mc_recipe`：本地配方库，不依赖联网。覆盖：
矿车/铁轨/动力轨/船/箱子/工作台/熔炉/桶/剪刀/盾/弓/箭/火把/床/运输矿车/漏斗矿车/动力矿车。
查不到时回退 `mc_learn` 查攻略。


## 建设自主边界

建设场景不再由宿主给标准方案：

- 她自己看资源/地形决定建不建、建什么；
- 不确定时用 `mc_recipe` / `mc_guide` / `mc_learn` 查；
- 查完按自己的判断做，不等待预设；
- 宿主只提供原语、安全边界和工具经验。

## 够不着/站不进去（2026-11-24）

现象：反复 `mc_find oak_log`→`mc_move_to 树坐标`→原地不动。

修复：

- `mc_move_to` 目标若是实心方块，自动改到相邻可站立点（含上方 1 格），回执带 `retargeted`；
- 目标更高时用 `pillarUpOnce()` 垫一块上去，最多 3 次，回执带 `climbed`；
- `mc_mine` 够不到且目标更高时先垫 1–2 块，超时放宽到 12 秒。

实测（独立创造世界）：

```text
move_to 树坐标 → retargeted=true，到达 101.3,102.0,100.5
mc_mine → 挖了 oak_log
```


## 攻略源：Wiki 优先（2026-11-24）

`mc_guide` 改为先查 [zh.minecraft.wiki](https://zh.minecraft.wiki/)：

- 提问先去掉“怎么/如何/做/搭”等口水词，再按物品名变体搜（石镐→镐）；
- 候选按“标题命中 > 摘要命中 − 版本/概览类噪声”排序；
- 取正文后按小节解析，优先「获取/使用/用途/种植/睡眠」等行动小节，合并两节生成步骤；
- Wiki 查不到才退回 B 站视频。

实测：

```text
怎么做石镐   → 镐 | 获取
怎么种小麦   → 小麦种子 | 种植
怎么搭自动门 → 红石电路
床 怎么睡觉  → 床 | 获取
```
