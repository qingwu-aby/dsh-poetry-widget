# 实践循环（v0.11.0）

目标：把“遇到问题 → 看事实 → 找原因 → 提假设 → 小步验证 → 复盘”变成她贯穿生活和游戏的默认能力，而不是某一次被教会的步骤。

## 三个入口

1. **Minecraft World**：她可以自己选择 `mc_inquire`（可选工具，不是固定流程）；
2. **生活复盘**：心跳每 6 小时检查一次；只有存在失败回执/明确问题才复盘，没有证据时不空想；
3. **聊天**：prompt 会带上她实践过的方法（`method` 账本），遇到卡住的事可以自己想到这些办法。

## 证据与结果

- 输入：失败的 World 回执、问题描述、方法记忆；
- 模型输出：`problem / cause / hypothesis / experiment / success / next`；
- 落盘：
  - `method` 全局账本（`methods.json`）：名字、做法、来源；
  - `journal`：一条“实践复盘”；
  - 游戏侧：`inquiry` / `plan` 记忆。

## 原则

- 基础设施只提供事实、资料和工具；**是否停下来分析、提出什么假设、怎么验证，由她决定**；
- 没有证据时不生成空泛复盘；
- 失败不是结论，是下一轮实验的材料。
