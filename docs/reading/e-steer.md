# 阅读笔记：How Emotion Shapes the Behavior of LLMs and Agents — A Mechanistic Study

> 论文：Moran Sun, Tianlin Li, Yuwei Zheng, Zhenhong Zhou, Aishan Liu, Xianglong Liu, Yang Liu.
> arXiv:2604.00005v1（Preprint, 2026-03，北航 / 南洋理工）。本地 PDF：`~/Desktop/How Emotion Shapes the Behavior of LLMs and Agents A Mechanistic Study.pdf`
> 记录时间：2026-10-26。阅读方法：用《矛盾论》的结构诊断 + 《实践论》的实践检验做一次对照，判断它对本项目（鲸鱼娘挂件）有没有用、怎么用。

## 1. 论文在做什么

- **问题**：情绪对 LLM/Agent 的行为是不是只是"表面风格"？还是像人一样，作为**任务处理中的机制性变量**在起作用？
- **方法 E-STEER**：把情绪放进连续的 **VAD（Valence–Arousal–Dominance，各 [-10,10]）** 空间；用 **Sparse Autoencoder（SAE）** 把第 k 层 hidden state 映射到稀疏潜空间，按正负样本对比筛出 VAD 相关潜神经元，再用 **activation patching / 方向注入** 在推理时加一个情绪方向（不改 prompt、不改参数），实现连续、可解释的情绪"转向"。
- **评测**：单步 LLM（客观推理 LogiQA2、代码 HumanEval、数理 Math；主观 TinyStories；安全 HarmBench）+ 多步 Agent（planner / decider / executor；HotpotQA、Scientific、GAIA）。
- **指标**：Answer Validity Rate、Task Success Rate、语境质量（相关/连贯/创造/简洁）、安全风险概率；Agent 侧计划有效率、重规划、理性选择率、执行完成率、整体成功率。

## 2. 论文的主要结论（数据摘自原文）

**单步 LLM**
- 客观任务：正效价使 Answer Validity 比负效价高 **33.1%**；质量（TSR）沿 VAD 呈**倒 U 型**，中等唤醒（arousal=+3）最好（+4.7%），整体最高比中性提升 **14.5%**；最优 dominance 随难度变化（简单任务低支配 -6 更好，难题 +3 更好）。三个维度里 **valence 造成的波动最大（71.2%）**。
- 主观任务：相关/连贯/创造都呈倒 U；负效价让输出更**简洁**（比正效价高 23.3% 简洁度），正效价容易冗余。
- 安全：低效价（-3）+ 低唤醒使安全风险概率下降 **52.7% / 21.7%**；高支配（+6）平均改善 **68.3%**；但极端情绪（高唤醒/高支配）能削弱安全对齐，甚至绕过防护。

**多步 Agent**
- 情绪偏差会沿决策链**累积**；模块级最优与系统级最优并不重合（多步、整合性）。
- 计划：valence=-3、arousal=-3 时计划有效率最好（+33.2%），正支配比负支配好 **79.8%**。
- 决策：正效价减少重规划（+6 时 -23.2%），理性选择率在 +3/+3/+3 最好（比负态高 42.4%）。
- 执行：受情绪影响最小（工具性操作）。
- 整体成功率：-3 效价 / +3 唤醒 / +3 支配最好，比中性提升 **16%~28%**（支配最大 28%）；系统级波动远大于模块级。

**方法学结论**
- 表示层 steering 的线性可控性（Pearson 0.92–0.98）明显高于 prompt 层（0.78–0.94）；prompt 里的连续数值常常不敏感。
- 局限：VAD 三维并不严格正交；没建模"情绪在任务过程中如何演化"；主要在 Qwen3-8B 上做，gpt-oss-20B 只是验证；这是白盒方法，需要模型权重与 SAE。

## 3. 用《矛盾论》读它：这篇论文的内部矛盾

- **主要矛盾**：情绪在行为中的**因果作用**（可干预、可测量）与既有研究把情绪当**表面风格/感知对象**的处理方式之间的矛盾。论文的解法不是调和，而是换层面——从 prompt 表面文本换到 hidden state 表示层，使"情绪"成为可控制变量。它的主要方面是**表示层干预**：因为这一点决定了它能得到连续、线性、可解释的结果，而 prompt 方法做不到。
- **内因与外因**：外因是心理学证据（正性情绪促进创造、过度唤醒损害表现、不安全感导致矛盾决策）；内因是 LLM 的 hidden state 里**已经编码了情绪相关特征**（SAE 能稳定找到），所以外部情绪提示才能通过内部表征起作用。论文的随机神经元对照实验（随机选择性能波动下降 70.9%）正是对"内因真实存在"的检验。
- **非单调/条件性**：情绪—行为不是线性加分，最优值随任务难度、维度、单步/多步而移动（倒 U、难度依赖、模块 vs 系统不一致）。这是"具体问题具体分析"的典型：不能把"积极情绪总是更好"当公式。
- **对抗性 vs 非对抗性**：情绪与安全的关系是对抗性张力（极端情绪削弱安全对齐），需要外部约束（对齐/守则），不能靠"情绪好就自然安全"。
- **同一性条件**：情绪能影响行为，需要三个条件同时成立——(1) 表示层存在可分离的情绪特征；(2) 干预方向与任务无关信息可分离（方向注入而非整体替换）；(3) 行为评测能捕捉到差异。缺一条，"情绪塑造行为"就不成立或不可测。
- **局限即矛盾未展开**：VAD 不正交、情绪不演化——论文自己承认这两点是"尚未解决的矛盾"，也是它结论只能算"静态切片"的原因。

## 4. 对我们（鲸鱼娘挂件）有没有帮助

**有，但不是照搬它的方法。**

直接照搬不可行：我们是 API 黑盒（DeepSeek / OpenCode Go），没有 hidden state 和 SAE，做不了表示层 steering；而且本项目明确"内在状态不量化"，VAD 打分与这个原则冲突。

但它的**机制性结论**可以迁移到我们的语义/行为层：

1. **情绪是行为的因果变量，不是装饰**：我们的 `self-drive` 让模型写 felt 再决定做什么，方向一致；可以更明确地把"此刻感受"作为行为选择的输入，而不是只当展示文案。
2. **非单调 & 条件性**：同一种情绪不是越多越好。对应到我们：避免"越饿越吃、越孤独越冒泡"的线性阈值（已去掉阈值），也避免同一种 felt 长时间主导。
3. **累积效应**：多步/长时间运行中情绪偏向会累积。我们的自处是 15–30 分钟一轮、持续整天的多步循环——应该防止"上一轮的情绪把下一轮推着走"（已在 v1.57 prompt 里加了一句"情绪会累积，别被上一轮推着走"）。
4. **安全相关性**：极端情绪会削弱谨慎。对挂件本身无害，但对"她替我做事/说话"的场景有意义：情绪再高/再低，涉及安全、风险、他人利益时仍要保持克制（我们模型侧有系统约束，prompt 不额外放开）。
5. **评测思路**：论文用 AVR/TSR/安全概率等行为指标验证情绪作用；我们不量化内在状态，但可以用**行为侧**指标做验证（例如：同一种行为重复率、自处 felt 的语义多样性、学习主题分布、自我修正次数），这符合"实践检验"。
6. **prompt 层 vs 表示层**：论文说 prompt 里连续数值不敏感，而文本情绪标签更有效——这反过来支持我们用**文字 felt** 而不是数值状态的设计。

**不建议采用的**：VAD 三维打分、SAE/hidden-state steering、用情绪分数驱动行为阈值；这些要么不可行（黑盒），要么与"不量化内在状态"的原则冲突。

## 5. 可落地的动作（已做 / 待做）

- 已做（v1.57）：自处 prompt 增加"情绪会累积，别被上一轮的情绪推着走"；其余 prompt 不加情绪分数。
- 待做（需观察后再决定）：
  - 行为侧指标：统计 felt 文本的主题重复度、同一种行为的重复率、跨天学习主题分布，作为"情绪是否把行为带偏"的实践检验（只做本地统计，不做内在打分）。
  - 如果需要更贴近论文的"情绪影响任务表现"，可在 agent 执行类任务（如长命令、写代码）前后记录 felt，对比完成率与报错率——但样本要足够才谈得上证据。

## 6. 一句话结论

这篇论文证明"情绪是 LLM/Agent 行为里可干预的因果变量，而且是非单调、随任务/阶段变化、会在多步中累积的"；它对本项目最大的帮助是**校准了我们对情绪的看法**（不是装饰、不是线性、会累积、与安全相关），而不是提供一套可直接抄的实现。我们的"文字状态 + 模型自处 + 不量化"路线与它的 prompt 层证据相容，但放弃它的白盒干预与 VAD 打分。
