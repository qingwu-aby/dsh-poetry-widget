# 像人一样生活：身体节律与自处动作

## 原则

不按 `hunger >= 75` 这种阈值替她决定行为；只记录**生活事实**，让她自己在自处时决定。

## 已记录的生活事实

`~/.dsh/.dsh-poetry/self-state.json`（v2）：

- 上次醒来 / 睡觉开始
- 上次吃饭 / 喝水
- **上次上厕所**
- **上次洗漱**
- 上次玩 / 社交 / 学习 / 自省 / 行动
- 她自己写的一句「此刻状态」

`describeTimeline()` 会把这些事实说成人话，注入自处、聊天、成长、阅读等 prompt。

## 自处动作

`self-drive` 的 kind 现在包括：

```text
eat | drink | toilet | wash | play | socialize | sleep | wake | learn | make
```

动作库也补了：

- 「去一下洗手间，顺便洗把手」
- 「去洗漱一下，把脸和手洗干净」

自处 prompt 明确写：

> 你有一副身体，日子要像人一样过：起床、洗漱、吃饭、喝水、上厕所、休息、睡觉，不是一直学习/玩游戏。

## 边界

- 她可以自己决定今天怎么过；
- 不把身体需求变成硬阈值；
- 不会假装做过没发生的事：只有模型在 kind 里标了 `toilet/wash`，时间线才更新。
