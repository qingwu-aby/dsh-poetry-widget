# ADR 0001：用绞杀者模式重构，不重写

- 状态：已采纳（2026-11-09）
- 背景：index.js 1725 行、86 个平铺模块、状态文件无 schema、模型调用各修各的；但插件已在真实使用，行为不能变。
- 决策：
  1. 采用绞杀者（strangler）模式：新结构逐步接管旧路径，旧路径保留 re-export 兼容；
  2. 每个 PR 必须 491+ 测试全绿、行为零变化、可独立回滚；
  3. 分层为 `kernel`（基础设施）/ `domain`（域 facade）/ `composition`（组装）/ `integration`（宿主适配）；
  4. 域之间只允许通过 facade 与事件通信，依赖方向由 `scripts/check-deps.mjs` 强制。
- 后果：短期 index.js 仍偏大（服务组装待分批迁移）；换来可增量发布、随时回滚、每步可验证。
