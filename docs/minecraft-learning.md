# 小鲸鱼怎么自学 Minecraft（v0.8.0）

目标：不是把攻略写死，而是让她自己查、自己试、自己记住。

## 流程

```
bot 遇到死亡/卡住/到学习间隔
  → POST /api/dsh-poetry/game-learn.json
  → 服务端 DuckDuckGo HTML 搜索「Minecraft 26.1 <主题> 新手 生存 建造 攻略」
  → 她的模型把搜索结果整理成 JSON：
       { lesson, steps[], happy }
  → 写入游戏记忆：
       method  ← lesson + 每个可执行步骤（带主题标签）
       plan    ← happy（她想在游戏里获得的开心）
  → 下一次 game-decide 的 prompt 会带上「方法：…」，她按自己学到的做
```

## 学习主题轮换

- 第一天的生存：木头、工具、庇护所、食物
- 建造自己的小屋：选址、材料、结构
- 农田与食物：种田、养动物、储存
- 在 Minecraft 里玩得开心：探索、装饰、宠物

死亡时额外学「怎样避免死亡、活得更久」；每 10 分钟最多一次，避免刷模型。

## 安全

- 搜索结果只作为资料，prompt 明确要求不照抄、不建议作弊、不破坏别人的东西；
- 学习结果只写 `method` / `plan` 分类，不混入聊天/日记/学习记忆；
- 模型输出不是合法 JSON 时整次学习作废，不落盘。
