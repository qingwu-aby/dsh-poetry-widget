# 先调研，再动手：小鲸鱼的项目学习方式

## 原则

大项目不是“进去就挖/就建”，而是先像人一样做功课：

```text
目标 → 需要哪些技能/材料/风险 → 查资料（B站/网页/旧记忆）
→ 写成阶段计划 → 小步执行 → 回执反馈 → 修正
```

适用于 Minecraft，也适用于学习、写作、做东西等长期项目。

## Minecraft 技能地图

### 1. 生存基础
- 砍树、木板、工作台、木镐/木斧/木剑
- 石头、石镐/石斧、火把、熔炉
- 食物来源（打猎/种植/钓鱼）
- 庇护所、门、床、箱子

### 2. 安家
- 选址：平地/靠山/水源/远离危险
- 材料：木头/石头/泥土/玻璃
- 照明、门、储物、农田、水源
- 防御：围墙、火把、封顶

### 3. 漂亮的房子
- 结构：地基、墙、屋顶、门窗
- 比例：不要一个方块盒子
- 材料搭配：原木/木板/石砖/玻璃
- 内饰：床、箱子、工作台、熔炉、地毯、画
- 照明：火把/灯笼/萤石

### 4. 长期生存
- 稳定食物农场
- 矿洞与矿物
- 下界与药水
- 附魔与装备
- 防御与备份

## 她应该怎么学

1. 先列出“完成目标缺什么”；
2. 用 `mc_guide` 看 B站攻略，用 `mc_learn` 查文字资料；
3. 把技能/材料/风险写进 `mc_plan`；
4. 只做计划里的下一步，不一次开工太多；
5. 用回执验证，失败就调整，不重复同一个失败动作。

## 已实现的引导（先自检，不硬门）

- World prompt 给出长期路线：生存 → 安家 → 漂亮房子；
- 每次大动作前先做自我检查：不会就查/学，会就直接做；
- 调研仍是选择，不强制每次查；
- `mc_plan` 传 `research=true` 时才自动查 guide；不传就按自己的判断设计；
- 如果她之前主动调研过同一 goal，蓝图会复用那份资料；
- 蓝图 prompt 会区分“有资料”和“没有资料也可以设计”；
- 自处 prompt 也改成“可以查也可以试，做完复盘”。

## 为什么不做成硬门

强制先调研会把学习变成合规动作，削弱试错、好奇和自主选题。
更合适的引导是：给工具、给选项、给复盘，让她自己决定先查还是先试。


## 搜索范围与来源（v0.35）

- `mc_learn` / `mc_inquire` / 实践复盘统一走 `webAccess.search`：
  - DeepSeek Search（有 key）
  - SearXNG（可选）
  - DuckDuckGo / Bing
  - Wikipedia
- 返回结果会带 `sources`（title/url）；`mc_plan` 记录 `verified` 与 `sources`：
  - `verified=true`：计划前调研过；
  - `verified=false`：凭经验设计，prompt 会提醒“不要重复同一个做法”。
- 不强制每次查；但如果计划未求证，来源状态会回执给模型。


## 资源优先级（v0.41）

- 食物、庇护所、工具、火把不稳定时，不建议接大房子/漂亮装饰/自动化；
- 资源匮乏时选低消耗、高回报的方案；
- `mc_plan` 会按背包材料数量自动缩小 `maxBlocks`，并写回 `resourceBudget`；
- 资源充足后才进入审美/自动化。
