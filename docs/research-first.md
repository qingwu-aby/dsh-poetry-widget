# 先调研，再动手：小鲸鱼的项目学习方式

## 原则

大项目不是“进去就挖/就建”，而是先像人一样做功课：

```text
目标 → 需要哪些技能/材料/风险 → 查资料（B站/网页/旧记忆）
→ 写成阶段计划 → 小步执行 → 回执反馈 → 修正
```

适用于 Minecraft，也适用于学习、写作、做东西等长期项目。

## Minecraft 技能地图

### 1. 生存基础
- 砍树、木板、工作台、木镐/木斧/木剑
- 石头、石镐/石斧、火把、熔炉
- 食物来源（打猎/种植/钓鱼）
- 庇护所、门、床、箱子

### 2. 安家
- 选址：平地/靠山/水源/远离危险
- 材料：木头/石头/泥土/玻璃
- 照明、门、储物、农田、水源
- 防御：围墙、火把、封顶

### 3. 漂亮的房子
- 结构：地基、墙、屋顶、门窗
- 比例：不要一个方块盒子
- 材料搭配：原木/木板/石砖/玻璃
- 内饰：床、箱子、工作台、熔炉、地毯、画
- 照明：火把/灯笼/萤石

### 4. 长期生存
- 稳定食物农场
- 矿洞与矿物
- 下界与药水
- 附魔与装备
- 防御与备份

## 她应该怎么学

1. 先列出“完成目标缺什么”；
2. 用 `mc_guide` 看 B站攻略，用 `mc_learn` 查文字资料；
3. 把技能/材料/风险写进 `mc_plan`；
4. 只做计划里的下一步，不一次开工太多；
5. 用回执验证，失败就调整，不重复同一个失败动作。

## 已实现的约束

- World prompt 明确：大项目先调研，不要一头扎进去；
- `mc_plan` 带 `goal` 时，先调用 guide 查资料，再生成蓝图；
- 蓝图 prompt 会带上查到的资料，并要求“资料没提到的不要假装知道”；
- 自处 prompt 也要求长期项目先列技能/材料/风险。
