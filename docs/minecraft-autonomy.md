# Minecraft 自主探索边界

## 原则

- 宿主只提供原语、反馈、经验层和安全边界；
- 不预设“先盖房再农场再红石”的任务树；
- 建设/红石/农场/交通/装饰都是她可选的探索方向；
- 顺序由她按资源、兴趣、失败经验决定。

## 查攻略

- 先查本地配方：`mc_recipe`
- 查不到：`mc_learn`（网络资料）或 `mc_guide`（B站攻略）
- 卡住：`mc_inquire` 分析原因
- 查完自己决定是否尝试，失败可复盘，不强制成功

## 安全边界

- 宿主不自动写 bot 代码、不自动注册任意原语；
- 红石/自动化先小规模试，不破坏生存资源；
- 交通载具以已可用能力为准：矿车可自建/骑/驾驶，boat 暂不生成；
- 生存世界不做批量验收，验证在独立世界进行。

## 目标

她可以自己提出建设目标、查资料、做计划、施工、复盘；
宿主不替她选“应该建什么”。
